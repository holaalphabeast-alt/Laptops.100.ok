# Laptops OK 100

Tienda en línea de laptops premium nuevas y seminuevas. La Paz, B.C.S.

## Estructura

```
index.html   Página completa (estilos y código incluidos)
img/         Fotos de producto y logo
.nojekyll    Hace que GitHub Pages publique los archivos tal cual
```

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en github.com, por ejemplo `laptops-ok100`.
2. Sube todo el contenido de esta carpeta: **Add file → Upload files**, arrastra los archivos y la carpeta `img`, y da clic en **Commit changes**.
3. Ve a **Settings → Pages**. En **Source**, elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`. Guarda.
4. En uno o dos minutos la tienda queda en `https://TU-USUARIO.github.io/laptops-ok100/`.

## Publicar con Netlify (desde GitHub)

1. En app.netlify.com: **Add new site → Import an existing project → GitHub**.
2. Elige el repositorio. Deja vacío el comando de build y pon `/` como carpeta de publicación.
3. Cada vez que subas un cambio a GitHub, Netlify actualiza la tienda sola.
